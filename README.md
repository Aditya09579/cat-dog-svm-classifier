# Cat vs. Dog Image Classifier

This project is a machine learning model that classifies images of cats and dogs using a Support Vector Machine (SVM). It was developed with Python, Scikit-learn, and OpenCV.

## Dataset

This model was trained on the "Dogs vs. Cats" dataset from Kaggle. You can download the data from the official source:

[https://www.kaggle.com/c/dogs-vs-cats/data](https://www.kaggle.com/c/dogs-vs-cats/data)

## How to Run

1.  Download the dataset and place the `train` folder in the root of this project directory.
2.  Install the necessary libraries: `pip install numpy scikit-learn opencv-python matplotlib`
3.  Run the script: `python svm_classifier.py`
